# Backup & Download Instructions

## Downloading WordPress Site Content

If mkphilatelic.com is hosted on WordPress, use these methods to backup/download:

### Method 1: WordPress Export (Recommended for Content)
1. Log in to WordPress admin (https://mkphilatelic.com/wp-admin)
2. Go to Tools > Export
3. Select "All content" and download XML file
4. Save to this directory as `mkphilatelic-export-YYYY-MM-DD.xml`

### Method 2: Full Site Backup (via cPanel/Hosting)
1. Log in to hosting control panel
2. Use backup tool or File Manager
3. Download complete WordPress installation
4. Extract to this directory

### Method 3: FTP Download
1. Connect via FTP to hosting server
2. Download entire WordPress directory
3. Save database dump separately
4. Store in this repository

### Method 4: Plugin-Based Backup
Use WordPress plugins like:
- All-in-One WP Migration
- UpdraftPlus
- Duplicator

## What to Backup
