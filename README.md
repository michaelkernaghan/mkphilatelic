# MK Philatelic

Personal philately website showcasing stamp collections and resources.

**Website:** https://mkphilatelic.com
**Contact:** mkphilatelic@gmail.com
**GitHub:** https://github.com/michaelkernaghan/mkphilatelic

## Overview

MK Philatelic is a comprehensive stamp collecting blog and catalog featuring collections organized by country, album type, and collection format. The site serves as both a personal collection inventory and a resource for stamp collectors.

## Site Categories

### Countries & Regions
- Australia, Austria, Belgium, Canada
- Cyprus, France, Germany, Great Britain
- Iceland, Japan, Luxembourg, Netherlands
- New Zealand, Poland, Russia, Spain
- Sweden, Switzerland, Turkey, USA
- World Wide collections

### Album & Page Types
- **Scott International** - Classic international album pages
- **Steiner Pages** - Specialized album pages
- **Davos Albums** - Swiss-focused collections
- **SpringBack Binder** - Modern binding system
- **Harris** - Harris album collections

### Collection Organization
- **Collections** - Complete collection sets
- **On Pages** - Stamps mounted on album pages
- **Packets** - Stamp packets and lots
- **Strips and Blocks** - Multiple stamp formats
- **Price Data** - Valuation information

## Content Format

Each collection entry typically includes:
- Date range covered
- Number of stamps
- Condition (Mint/Used)
- Album page type
- Collection details and notes
